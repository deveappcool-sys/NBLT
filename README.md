# NBLT

📺 NBLT 是一款专为 Android TV 设计的第三方哔哩哔哩客户端，重点针对电视盒子的播放性能、解码兼容性和遥控器操作体验进行深度优化。

## 极致播放优化

- 针对低性能和老旧电视盒子优化播放稳定性
- 根据设备能力自动选择 AVC 或 HEVC 解码方案
- 硬件解码失败时自动切换兼容解码器
- 播放异常时自动恢复，并尽量保持原播放进度
- 自适应选择视频 CDN，自动降低故障线路优先级
- CDN 预连接与性能评分，减少视频加载等待
- 切换清晰度和播放源时复用播放器，降低黑屏与卡顿
- 优化首帧加载过渡，减少加载文字和进度条闪烁
- 针对内存、缓存和网络请求进行电视端专项优化

## 主要功能

- 扫码登录
- 动态与观看历史
- 视频搜索、收藏和稍后再看
- UP 主空间与视频详情
- 视频播放、弹幕和清晰度切换
- 适配电视遥控器的焦点导航

## 构建

需要安装 Android Studio、JDK 17 和 Android SDK。

构建命令：`./gradlew assembleDebug`

APK 输出目录：`app/build/outputs/apk/debug/`
